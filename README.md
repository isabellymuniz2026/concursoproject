# Concurso em Foco

Projeto em desenvolvimento para ajudar candidatos a organizar a preparação para concursos públicos.

## O que já funciona

- Cadastro de concursos pelo nome.
- Exibição dos concursos cadastrados em uma lista.

Nesta versão, a lista é reiniciada quando a página é atualizada.

## Próximas funcionalidades

- Salvar os concursos cadastrados.
- Organizar matérias, revisões e sessões de estudo.
- Acompanhar o progresso e os prazos de cada concurso.
- Analisar editais em PDF e gerar planos de estudo com IA.
- Gerar cadernos de questões sobre tópicos já estudados.

## Como rodar no computador

Com Node.js e npm instalados, execute os comandos abaixo a partir da raiz do projeto:

```bash
cd frontend
npm install
npm run dev
```

Abra no navegador o endereço que aparecer ao lado de `Local:` no terminal.

O frontend usa React, TypeScript e Vite.
